# Примеры

[English](README.md)

Конфиги, которые делают что-то настоящее. Укажите на любой откуда угодно:

```console
$ owlab --config examples/luci-theme-footstrap up
```

| | |
|---|---|
| [luci-theme-footstrap](luci-theme-footstrap/owlab.yaml) | Тема LuCI: четыре роутера, чтобы покрыть оба менеджера пакетов и оба фида LuCI, шаг сборки для генерируемого CSS и сторонние приложения, с чьими стилями теме приходится делить страницу |

Это конфиги, против которых проекты действительно разрабатываются, а не
наброски. Написаны под правку исходников самого проекта; чтобы работать с
выпущенной версией, уберите блок `install:`/`post_sync:` и назовите пакет в
`extra_packages:`.
